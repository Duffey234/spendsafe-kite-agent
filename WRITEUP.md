# SpendSafe Kite Agent — write-up (Kite track)

SpendSafe is a SERV Reasoning agent with hard spending limits for safe agent payments. SERV proposes approve / refuse / reduce; deterministic code enforces per-tx, total, and TTL caps and screens payees with PayGuard before any spend. We ran a live Base USDC x402 payment (0.005 USDC) through Settlement Check to an allowlisted paid endpoint, with a Basescan receipt, plus live SERV decide and live PayGuard OFAC preview. Kite Passport signup is prepared; the passkey approval that unlocks Passport session execute still needs a human in the browser. Creativity: model proposes, code decides, fail closed. User readiness: `npm test` / `npm run demo` with clear live vs simulated labels. Revenue potential: the same envelope wraps any x402 catalog API for agent checkout without giving a model a raw wallet.
